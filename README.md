
# ☕ Cafeteria Aroma

Meu primeiro projeto de desenvolvimento web!

## Sobre o projeto

Um site simples para uma cafeteria fictícia, desenvolvido como parte dos meus estudos de HTML, CSS, JavaScript, Git e GitHub.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Funcionalidades

- Página inicial da cafeteria
- Apresentação dos produtos e serviços

## Como executar

1. Clone este repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` no navegador.
